# PushLocal Visual Identity

## Brand
**Name:** PushLocal  
**Public lockup:** PushLocal WP  
**Tagline:** **Local code. Live in seconds.**

## Positioning
PushLocal is a focused developer utility, not a general file manager. The visual system should feel fast, precise and safe.

## Palette
- Ink: `#101828`
- Indigo: `#5B5CF6`
- Indigo Dark: `#4746D9`
- Indigo Soft: `#EEF0FF`
- Mint: `#33DDB0`
- Surface: `#FFFFFF`
- Soft Surface: `#F7F8FC`
- Border: `#E4E7EC`
- Muted: `#667085`
- Danger: `#C92A2A`

## Voice
Short, calm, developer-focused. Avoid hype, mascots and enterprise jargon.

## Product principles
1. Local-first.
2. Explicit before destructive actions.
3. Show exactly what will change.
4. Never hide safety state.
5. No PushLocal cloud dependency.
